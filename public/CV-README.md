# Instrucciones para el CV en PDF

## Opción 1: Usar la vista previa (Recomendado)
1. Haz clic en "Vista Previa" en la sección CV del portafolio
2. En la vista previa, haz clic en "Descargar PDF"
3. Tu navegador abrirá el diálogo de impresión
4. Selecciona "Guardar como PDF" como destino
5. Guarda el archivo

## Opción 2: Agregar tu propio PDF
Si deseas subir tu propio PDF generado externamente:

1. Coloca tu archivo PDF en la carpeta `public/` con el nombre: `cv-juan-rafael-calzada.pdf`
2. El botón "Descargar CV" funcionará automáticamente

## Opción 3: Generar PDF con herramientas online
Puedes usar la vista previa del CV y:
1. Copiar el contenido
2. Usar herramientas como:
   - Canva
   - Google Docs
   - Microsoft Word
   - Resume.io
3. Exportar como PDF y colocarlo en `public/`
